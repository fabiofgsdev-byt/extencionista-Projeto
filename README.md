# AMIS – Cadastro de Assistidos

Sistema desenvolvido como Projeto Extensionista do curso de **Análise e Desenvolvimento de Sistemas** da **UNINTER**.

O objetivo é facilitar o cadastro e a organização dos assistidos da **AMIS (Associação Morumbi de Integração Social)**, oferecendo uma solução simples, intuitiva e de fácil utilização para a equipe da instituição.

## Demonstração

🔗 Projeto online: https://fabiofgsdev-byt.github.io/extencionista-Projeto/

## Funcionalidades

- Cadastro de assistidos
- Registro de responsáveis
- Seleção de atividades oferecidas pela AMIS
- Listagem dos cadastros realizados
- Exclusão de registros
- Armazenamento local utilizando LocalStorage
- Interface responsiva e de fácil navegação

## Atividades disponíveis

- Balé
- Judô
- Futsal
- Coral
- Instrumentos de Corda
- Instrumentos de Sopro
- Projeto Semear

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Objetivo social

Este projeto foi criado para contribuir com a organização dos atendimentos da AMIS, tornando o processo de cadastro mais rápido, reduzindo registros em papel e facilitando o acesso às informações dos assistidos.
